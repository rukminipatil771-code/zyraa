
# ZYRAA
fashion website built for learning with vite and typescript.based on a google ai studio template.

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/2fc44efb-13b9-4654-9d6c-52ed1980ae82

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
